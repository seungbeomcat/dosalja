# 도살장 격전지 계산기 V1.5.0

기준일: 2026-09-23

## V1.5.0 UI 개편
- 기존 V1.4.1 계산 데이터/공식/검증/결과 출력 로직을 유지합니다.
- 사용법 박스를 제거하고 `계산 종류 + 닉네임` 입력 구조로 변경했습니다.
- 1구역: 보스 체력만 별도 입력하며 닉네임 입력창에는 닉네임만 입력합니다.
- 2구역: 루이/루니/루나/바나냥 중 하나를 선택하고 닉네임만 입력합니다. 선택 보스는 내부 계산 입력에 자동 반영됩니다.
- 개인 초대형: 늑대/해적/고양이/음식 중 하나를 선택하고 닉네임 1명만 입력합니다. 선택 지역은 내부 계산 입력에 자동 반영됩니다.
- 개인 종합 격추: 추가 선택 없이 닉네임 1명만 입력합니다.
- 모드별 보조 UI는 상호 배타적으로 표시됩니다.
- 길드원 격추표는 첫 화면 하단에 상시 표시합니다.
- `길드 초대형 계산`은 같은 페이지 안에서 펼침/접힘으로 동작합니다.
- 보스/지역 선택 버튼과 길드원 격추표 탭은 메인 실행 버튼과 다른 보조 색상 체계를 사용합니다.
