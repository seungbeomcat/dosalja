# 도살장 격전지 계산기 V 1.2.2

GitHub Pages 전체 업로드 파일 / 2026-09-17 개편본

## V1.2.2 업데이트 핵심

- 서버격추를 길드원 고정 데이터에서 분리
- 계산 전 현재 서버격추를 `0% / 1% / 2% / 3% / 4% / 6%` 중 사용자가 직접 선택
- 서버격추 미선택 상태에서는 계산하지 않도록 차단 (`0%`도 직접 선택해야 함)
- 서버격추 선택 변경 시 이전 계산 결과를 그대로 사용하지 않도록 처리
- 종합격추 계산식은 `기본격추(탈것 포함) + 선택 서버격추 + 지역격추` 유지
- 계산 결과에 `이번 계산에 선택된 서버격추는 X%입니다.` 표시
- 길드원 격추 현황표에서 서버격추 열 삭제
- 현황표에서 `지역격추 → 종합격추` 형태의 사전 계산값을 제거하고 원본 지역격추만 표시
- 상층 현황표: `닉네임 / 기본 / 1구역 지역 / 2구역 지역`
- 일반·균열 현황표: `닉네임 / 기본 / 늑대 / 해적 / 고양이 / 음식`
- 모바일 좌우 스크롤 시 닉네임 열 고정
- `닉네임만 입력 : 지역별 본인의 종합격추 확인` 기능 추가
- 닉네임 단독 입력 시 선택한 서버격추를 반영하여 상층 1·2구역 및 일반·균열 각 지역의 종합격추 표시
- 기존 `닉네임만 입력 → 2구역 자동 분배` 동작 폐기
- 1구역 체력 분배, 2구역 보스 분배/이탈 기준, 일반·균열 계산 및 기존 실측 보정 구조 유지
