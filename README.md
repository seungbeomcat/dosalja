## V1.4.0 초대형 스코어 계산
- 기존 계산기가 접속·새로고침 시 항상 첫 화면입니다.
- 제목 아래 `계산기 | 균열(은하) 초대형` 탭으로 전환합니다. 탭 전환 중 양쪽 입력값은 유지됩니다.
- 초대형 지역과 서버격추는 처음에 미선택입니다. 서버 0%는 정상적인 선택값입니다.
- 기존 계산기와 새 탭의 서버 선택은 독립적이며, 15명 데이터 원본은 동일하게 사용합니다.
- 표: 닉네임 / 초 입력 / 기본격추 / 지역 / 예상 스코어. 지역 헤더는 선택 시 늑대·해적·고양이·음식으로 변경됩니다.
- 시간은 0~1,200초 정수입니다. 빈칸·0은 참여 제외입니다. 잘못된 입력이 있으면 총합계를 표시하지 않습니다.
- 개인 예상 스코어 = 반올림(1,050 × 사용 초 × (1 + (기본 + 서버 + 지역)/100) + 개인 최소 점수).
- 최소 점수는 시간이 양수인 참여자에게 이번 보스 1회분만 가산합니다. 길드 합계는 화면에 표시된 개인 예상 스코어들의 합입니다.
- 기존 63 WAVE/60초 모델을 평균 시간당 점수로 환산한 추정입니다. 초대형 전용 실측 보정이나 순위·포인트 예측은 포함하지 않습니다.
- 사용 시간 초기화는 새 탭의 시간만 지우며 지역·서버 선택은 유지합니다.
- 총합계는 표 밖 별도 박스로 표시합니다. 시간/지역/서버를 변경하면 자동 갱신됩니다.
- 지역 선택은 요청한 4개 지역만 지원합니다. 은하 중앙 지역은 데이터·규칙 확정 전 포함하지 않습니다.

## 계산 규칙
- 서버격추 선택값: 0 / 1 / 2 / 3 / 4 / 6%. 첫 진입 미선택. 0과 미선택은 다릅니다. 자동 초기화 없음.
- 종합격추 G = 기본격추(탈것 포함) + 선택 서버격추 + 해당 지역격추.
- 화력 P = 100 + G. 분배는 P / 참여자 P 합계.
- 실전 목표 합계 100, 1구역 정수 담당 HP 합계 입력 HP. largest remainder, 소수점 동률은 G 우선.
- 최소 점수 M은 최종 점수에 전투당 한 번 가산: Score = B × (1 + G/100) + M. 피해량·HP 분배·완료시간에는 더하지 않습니다.
- 시간 모델 유지: WAVES_PER_SEC = 63/60, SCORE_PER_WAVE = 1000, SAFE_SEC = 1.
- 개별 전투시간 설정은 모두 동시에 입장하는 조건. 각 대상자의 시간 × 기존 실전 화력으로 피해량을 계산하고, 남은 HP를 정상 참여자의 화력비로 분배합니다.
- 최대레벨 HP: 루이 Lv20 350,000 / 루니 Lv30 400,000 / 루나 Lv40 450,000 / 바나냥 Lv50 500,000.
- 시간 입력: 옥돔30초 / 옥돔 30초 / 옥돔30 / 옥돔 30. 복수 대상자·혼합 입력 가능.
- 결과 하단은 선택 서버격추와 종합격추 공식 두 줄만 표시합니다.
