## V1.2.4 마이너 업데이트
- 길드원 격추표에서 `기본` 바로 다음에 `최소 점수` 열 표시
- 현재 격전지 최소 점수 증가: 돗돔 4,500 / 혀녕 1,500 / 승부왕 1,000 / 나머지 12명 0
- `격전지 최소 점수 증가`는 격추%가 아니며 기본·서버·지역격추에 합산하지 않음
- 보스에게 피해를 주지 못해도 보장되는 점수이며, 전투당 최종 점수에 딱 1회만 가산
- 전투가 1초든 40초든 최소점수 가산 횟수는 1회로 동일
- 기존 보스 HP 분배·화력비·예상 완료시간 계산식은 변경하지 않음
- 격전지 최소 점수 증가는 메달을 통해 올릴 수 있음 (아카데미 미적용)
- 상층 표 헤더: `닉네임 / 기본 / 최소 점수 / 1구역 / 2구역`
- 상층의 `최소 점수 / 1구역 / 2구역` 열 폭 동일
- 일반 표기: `[일반•균열•은하] 늑대, 해적, 고양이, 음식 지역 격추`
- 두 표 모두 헤더는 가운데 정렬, 닉네임 데이터는 좌측 정렬, 숫자 데이터는 우측 정렬
- 두 표의 지역 설명 아래에 격전지 최소 점수 증가 안내문 2줄 추가

## 계산 기준
- 종합격추 = 기본격추(탈것 포함) + 사용자가 선택한 서버격추 + 지역격추
- 서버격추는 0% / 1% / 2% / 3% / 4% / 6% 중 계산 전에 직접 선택
- 최종 스코어 = 기존 스코어 계산 결과 + 개인 격전지 최소 점수 증가(전투당 1회)
- 최소점수는 지속 DPS, 보스 HP 분배, 참여자 화력비, 클리어 예상시간에는 반복 가산하지 않음
- 실제 최종 스코어 역산 시 개인 최소점수를 1회 차감한 뒤 기존 계산식 적용
