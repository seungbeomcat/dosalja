# 도살장 격전지 계산기 V1.3.0

GitHub Pages 전체 업로드 파일 / 2026-09-20

## V1.3.0
- 기본 상태는 `시간 제한 계산 OFF`입니다. OFF에서는 V1.2.4의 기존 계산 방식과 입력 방식을 그대로 사용합니다.
- 사용자가 직접 `시간 제한 계산 ON`을 선택한 경우에만 시간 제한 표기를 해석합니다. OFF가 항상 기본이며 자동 ON은 하지 않습니다.
- ON에서는 `옥돔30초`, `옥돔 30초`, `옥돔30`, `옥돔 30`을 모두 30초 제한으로 인식합니다. 서로 다른 표기를 한 입력에서 섞어 사용할 수 있습니다.
- ON 사용 예시: `예 ) 루나 / 돗돔 승부 옥돔30초`
- 시간 제한 대상자는 1명뿐 아니라 2명, 3명 이상도 입력할 수 있습니다.
- 시간 제한 계산은 2구역 보스에서만 동작합니다.
- 시간 제한 계산에서는 해당 보스군 최대 레벨 HP를 사용합니다: 루이 Lv.20 350,000 / 루니 Lv.30 400,000 / 루나 Lv.40 450,000 / 바나냥 Lv.50 500,000.
- 모든 참여자는 전투 시작과 동시에 입장하는 전제입니다.
- 각 시간 제한 대상자의 `제한시간 × 현재 2구역 실전 화력` 피해량을 각각 계산해 최대 레벨 HP에서 먼저 차감합니다.
- 차감 후 남은 HP만 시간 제한이 없는 정상 참여자에게 기존 2구역 화력비 방식으로 분배합니다.
- 시간 제한 대상자의 결과표 이탈 기준 자리에는 `30초`처럼 입력한 시간을 표시합니다.
- 정상 참여자의 이탈 기준·종합격추·계산 분배·실전 목표 및 예상시간은 기존 2구역 방식과 연결됩니다.
- ON 상태에서만 입력법 설명이 나타나고, OFF에서는 설명 영역이 레이아웃에서 사라집니다.
- 시간 제한 예시 라벨은 기존 사용법 예시와 동일한 라벨 스타일을 사용합니다.
- 시간 제한 ON/OFF는 A안 한 줄형 UI로 축소해 OFF 상태에서 불필요한 큰 박스를 차지하지 않습니다.
- 전체 색상은 로열 바이올렛 B안으로 변경하고, 제목은 선택된 세련된 고딕체 방향(과도한 Black 굵기 제거)으로 조정했습니다.

## 결과 하단 공통 안내
모든 계산 결과에서 아래 두 줄만 표시합니다.
- `선택된 서버격추는 X%`
- `종합격추 = 기본격추(탈것 포함) + 서버격추 + 지역`

## 현재 핵심 계산 기준
- 서버격추는 사용자가 `0 / 1 / 2 / 3 / 4 / 6%` 중 직접 선택합니다. 자동 선택하지 않습니다.
- 종합격추 = 기본격추(탈것 포함) + 선택 서버격추 + 해당 지역격추.
- 실전 시간 보정 상수: `WAVES_PER_SEC = 63/60 = 1.05`, `SCORE_PER_WAVE = 1000`.
- 격전지 최소점수는 보스 HP 분배·화력비·클리어시간을 변경하지 않으며 최종 스코어에 전투당 1회만 가산됩니다.
