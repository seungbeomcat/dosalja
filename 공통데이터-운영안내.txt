도살자 길드 공통 데이터 / 최초 전환 안내

1. 최초 배포 순서: 도살자 V1.9.1 전체 파일 먼저 업로드 (shared/guild-core.js 포함). 업로드 완료 후 보스 V3.5.0, 균열·은하 OPS V0.4.0을 각각 기존 저장소에 업로드합니다.
2. 핵심 파일: /dosalja/shared/guild-core.js
   - members : 기본격추·지역격추·상층격추·최소점수
   - aliases, formerNames : 현재 별칭·과거 닉네임 대응
   - rules / bosses / 계산 함수 : 도살자에서 관리하는 공통 수치와 계산 규칙
3. 이후 격추정보/공통 계산식만 바뀌면 도살자 저장소의 shared/guild-core.js만 변경하여 배포하면 보스와 OPS도 페이지 접속 시 최신 값을 읽습니다. ZIP으로 작업할 때는 도살자 전체 ZIP만 재배포해도 됩니다.
4. 보스와 OPS의 저장 데이터(Firebase)는 이전과 같은 컬렉션/경로를 계속 사용합니다. 과거 처치기록, 완료 회차 및 보상기록은 이 전환으로 수정하거나 삭제하지 않습니다.
5. 두 보조 페이지는 공통 파일을 읽지 못할 경우 최초 이관 시점의 내장 데이터로 임시 표시하며 화면 위에 연결 실패 경고가 나옵니다. 정상 복구 후 페이지를 다시 열면 최신 중앙 데이터를 읽습니다.
6. 중요: 도살자 파일을 업로드할 때 반드시 'shared' 폴더도 함께 업로드하세요. 중앙 데이터는 /dosalja/shared/guild-core.js URL에서 제공되어야 합니다.
7. 고유한 2구역 참여/보상 배분 공식과 OPS 수동 스코어/자원 관리 기능은 각 페이지의 독립 기능으로 유지합니다. 공통 길드원 데이터와 공통 전투 계산만 중앙화했습니다.
8. 기존에 사용한 저장소 주소와 보스/OPS의 링크는 변경되지 않습니다.
9. 데이터만 바꿨을 때 이전 기록에 소급 재적용하지 않습니다.

10. 도살자 길드원 격추정보의 update 문구는 index.html과 shared/guild-core.js의 서버 Last-Modified 중 더 최근 시각을 우선합니다. 서버가 수정시각을 보내지 않는 경우 빌드 기준 시각으로 표시됩니다.

11. V1.9.1 닉네임 변경: 바포메트 → 항정살 (격추 35.5% 유지). 과거 기록은 당시 닉네임으로 보존됩니다.
12. 이미 V1.9.0 전체 파일을 배포하셨다면 이후 이번 변경을 반영할 때는 도살자 저장소 shared/guild-core.js 파일 한 개만 교체하면 됩니다. 보스 V3.5.0·OPS V0.4.0을 재배포하지 마세요.
