도살장 격전지 계산기 V 1.1.2
GitHub Pages 전체 업로드 파일 / 2026-09-13 실측 보정본

업데이트 핵심
- 계산기 화면 최신 반영일을 2026-09-13으로 갱신
- 공유 버튼 문구를 `단톡방 공유용 이미지 만들기(클릭)`으로 변경
- 돗돔/승부왕 실측 데이터를 바탕으로 상층 1구역·2구역·일반/균열 공통 피해 구조 보정
- 공통 실측식: 완료 WAVE × 1,000 × (1 + 종합격추/100) + 개인 최소점수
- 시간 계산 대표값: 60초 부근 완료 63 WAVE(약 1.05 WAVE/초)
- 상층 예상 완료시간에 ±1초 안전범위 적용
- 1구역 남은 체력 분배에 개인 최소점수를 내부 반영한 동일시간 차등분배 적용
- 2구역 보스 체력 분배/이탈 기준에도 개인 최소점수를 내부 반영
- 일반·균열 1/2/3분 예상딜을 실측 WAVE 구조로 보정하고 ±1 WAVE 범위 표시
- 최소점수 내부값: 돗돔 4500 / 승부왕 1000 / 혀녕 1000 / 나머지 0
  ※ 최소점수는 내부 계산 데이터이며 길드원 격추표에는 표시하지 않음
- 혀녕 일반·균열 지역격추: 늑대 8 / 해적 6 / 고양이 6 / 음식 6
- 승부왕 일반·균열 지역격추: 늑대 0 / 해적 1 / 고양이 0 / 음식 1
- 기존 최신 기본격추·상층 지역격추·별칭·보스 HP 데이터 유지
- 입력창/상층 가로스크롤/길드원 상세표 UI 유지
